How to Use a Random Name Picker in Meetings and Workshops

By Eduardo Dionisio · November 4, 2026 · 3 min read

A random name picker can remove the awkward pause after “who wants to go first?” It can also distribute airtime, rotate small responsibilities and add energy to a workshop. The key is to use randomness as a transparent facilitation rule, not as a way to surprise or embarrass people. This guide shows how to use the Wheel Of List name picker in in-person, hybrid and remote meetings.

Good uses for a random name picker

The tool works best when every outcome is acceptable and the task is low stakes. Useful examples include choosing the first speaker, rotating the daily stand-up order, assigning breakout-room reporters, selecting who reads the next prompt, choosing a retrospective activity or deciding which team presents first.

For anything sensitive — performance feedback, personal disclosures, conflict resolution — invite volunteers instead. Equal probability does not automatically make an activity psychologically safe.

Step 1: define what the spin decides

State the rule before adding names. “This spin chooses our presentation order” is clearer than “let's see who the wheel picks.” A specific rule helps participants understand the consequence, check that the list is correct and raise a concern before the result appears.

Step 2: build a clean participant list

Paste one name per line. Use the names people use in the meeting, remove duplicates and confirm that nobody is missing. For a large workshop, use team names instead of individuals when the activity belongs to a group. You can create a shareable wheel link in advance, but check attendance just before the session.

Step 3: decide whether names can repeat

For a speaking order, remove each person after selection so everyone gets exactly one turn. For repeated questions where every round should be independent, keep names on the wheel. Explain which mode you are using: repeated draws are mathematically fair over time, but a short meeting can still pick the same person twice.

Step 4: give people a pass

A fair meeting is not the same as a forced meeting. Let a selected participant say “pass” and spin again without needing to justify it. This keeps the playful energy while respecting accessibility needs, camera or audio problems, and moments when someone needs more preparation time.

Step 5: show the draw

In a room, project the wheel. In a remote call, share the browser tab and keep the full list visible before spinning. Watching the same animation creates a common reference point and makes the decision feel neutral. Avoid repeated rerolls after an inconvenient result; if a result is invalid, say why before spinning again.

Meeting formats that work well

Meeting activityRecommended setup
Daily stand-up orderOne name each, remove after selection
Workshop presentationsUse team names, record the full ranking
Retrospective promptPut prompt names on the wheel instead of people
Breakout reporterOne representative per group, allow a pass
Facilitator rotationSave the list and remove recent facilitators

Use the results panel as an agenda

When the wheel creates an order, open the Results tab and use the ranking as the running agenda. First place appears at the top, followed by every later selection. Share the numbered result in the meeting chat so participants know when they are coming up and can prepare.

Remote and hybrid meeting tips

Increase browser zoom if names are small on a shared screen, mute the sound when it would interrupt conversation, and pause briefly after the result so everyone can read it. In hybrid rooms, have the facilitator control the wheel from the shared display rather than asking remote participants to open separate copies that could produce different draws.

A simple facilitation script

Try: “I have everyone on the wheel. We'll spin once for the presentation order, remove each team after it is picked, and anyone can ask for a pass. Does the list look right?” That twenty-second explanation establishes consent, transparency and the exact meaning of the draw.
