What's New: A Smarter Results Podium and Live Ranking

By Eduardo Dionisio · November 4, 2026 · 2 min read

The results area on Wheel Of List has a new look and a clearer job: turn a sequence of spins into a ranking that anyone can understand at a glance. The refreshed panel is live now, with a podium-inspired design, better visual hierarchy and a result order that always runs from the highest position to the lowest.

A podium you can read in one second

First place now gets a trophy treatment, second place a silver medal, and third place a bronze medal. The colour, icon and position number work together, so the ranking remains easy to follow even when names are similar or the list grows during a live session.

From fourth place onward, each result keeps a strong numbered position without competing visually with the podium. This makes the panel useful for a single winner, a top three, or a longer finish order.

Highest rank first, every time

The ranking reads naturally from top to bottom: winner first, then runner-up, third place and the remaining results. New spins are added to the end of that order instead of pushing the current leader away from the top. It is a small behaviour change that makes a big difference when the wheel is displayed on a projector, shared in a meeting or used to run several rounds.

A live result count

The panel now shows how many results have been recorded. The same count appears on the Results tab, which makes it easy to switch between the wheel editor and the ranking without losing track of the session. An empty state explains what will happen before the first spin; after that, the list updates automatically.

Cleaner result sharing

The Share Results action now produces a simple numbered list that matches what is visible on screen. That is useful for pasting a final order into a group chat, classroom platform or event recap. The names are read from the visible ranking, so the shared version and the displayed version stay aligned.

More depth without getting in the way

The wider interface also received a visual pass. Layered gradients, subtle light and a slow background movement give the page more depth while keeping the wheel and result names as the focus. Glass-like surfaces separate the controls from the background, and the results panel uses stronger contrast for comfortable reading.

Motion respects the device's reduced-motion preference. When that preference is enabled, decorative animation is removed so the interface remains calm and accessible.

Why we made this update

A wheel spin is exciting, but the result is what people need to act on. The previous list recorded winners, yet it did not make the final order feel complete. The new podium closes that gap: it works as a lightweight scoreboard for games, presentations, workshops, classrooms, raffles and any activity with multiple picks.

Try the new results panel

Add a few names, spin more than once and open the Results tab. The first three positions receive podium styling automatically, and the rest of the ranking stays ordered underneath. No account or setup is required.
